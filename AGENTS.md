# Project harness

Before making changes, read and follow [docs/base-standards.md](docs/base-standards.md).
It is the single source of truth for this repository's workflow and quality
rules.

For reusable workflows, load the matching skill from `.agents/skills/`. OpenSpec
skills are generated by OpenSpec; project-specific skills are maintained by this
team.

Every material change starts from a Jira `SP-<number>` work item and uses that
key in the branch, OpenSpec change, and pull request. Do not implement behavior
whose scope or acceptance criteria have not been accepted by the team.
